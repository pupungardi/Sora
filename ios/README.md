# Sora — iOS

SwiftUI app (`app.sora.ios`) generated by XcodeGen, with
`NuvioEngine.xcframework` as a local Swift package and MPVKit as an SPM
dependency.

```
ios/
  project.yml                    XcodeGen spec
  Sources/Sora/SoraApp.swift
  Sources/Sora/ContentView.swift
  Sources/Sora/PlayerView.swift   AVPlayer for now; MPVKit is the next step
  Sources/Sora/EngineClient.swift PlayerModel + engine bridge
  Sources/Sora/Info.plist
  Vendor/                        created by scripts/build-apple.sh (gitignored)
```

## Build

macOS only:

```bash
brew install cmake ninja xcodegen
scripts/build-apple.sh --build     # or --open to work in Xcode
```

The script builds `NuvioEngine.xcframework` (OpenSSL + libtorrent, slow the first
time), stages the engine Swift package under `ios/Vendor/`, then runs
`xcodegen generate`. Without that staging step `xcodegen` fails, because
`project.yml` references a local package that does not exist yet.

Deployment target: iOS 16.1 (the engine's minimum). Set `DEVELOPMENT_TEAM` in
`project.yml` for device builds.

## Status

Never compiled. `EngineClient` is written against the engine's Swift API
(`create(configuration:)`, `addMagnet`, `files(for:)`,
`prepareStream(torrentID:fileIndex:filenameHint:)`). Until the xcframework is
staged, the `#if canImport(NuvioEngine)` fallback compiles and magnet input
reports "engine belum dibangun"; direct URLs play through AVPlayer.

MPVKit is declared but not used yet. Either replace `PlayerView` with an
MPVKit-backed view, or remove the dependency until you do — an unused
LGPL-3.0 framework in the build is a liability, not a feature.
